## 📝 Description
Sticky Title keeps discussion titles always visible while scrolling in Flarum, enhancing navigation and user experience. Never lose track of which discussion you're reading!

## 🎯 Key Features
### Mobile Features
- **Smart Header Display:** Shows discussion title in mobile header based on scroll direction
- **Customizable Scroll Behavior:** Choose when to show titles - always, on scroll up, on scroll down, or never
- **Smooth Transitions:** Elegant fade in/out animations for better UX
- **Responsive Design:** Optimized for all mobile screen sizes

### Desktop Features  
- **Sidebar Title Panel:** Beautiful discussion title panel in the sidebar
- **Tag Integration:** Shows discussion tags for better context
- **Quick Navigation:** Click to jump to the first post instantly
- **Scrubber Enhancement:** Replaces "Original Post" with actual discussion title

### Admin Settings
- **Mobile Scroll Direction:** Configure when titles appear on mobile devices
- **Scrubber Title Replacement:** Toggle discussion title in scrubber
- **Desktop Title Panel:** Enable/disable sidebar title panel

## 📥 Installation

Install with composer:
```bash
composer require huseyinfiliz/sticky-title
```

Or install with Extension Manager:
```
huseyinfiliz/sticky-title
```

## ♻️ Updating

```bash
composer update huseyinfiliz/sticky-title
php flarum cache:clear
```

## 🗑️ Removal

```bash
composer remove huseyinfiliz/sticky-title
php flarum cache:clear
```

## ⚙️ Configuration

1. Enable the extension in your admin panel
2. Navigate to the extension settings
3. Configure your preferences:
   - **Mobile Scroll Direction**: Choose when to show titles on mobile
   - **Scrubber Title**: Enable/disable title in scrubber
   - **Desktop Panel**: Show/hide sidebar title panel

## 🔧 Requirements

- **Flarum:** 1.8.1+
- **PHP:** 8.1+
